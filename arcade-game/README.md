# 별조각 퀘스트 (Starshard Quest)

휴대폰 가로 화면으로 즐기는 **1인용 2D 횡스크롤 액션 아케이드 게임**입니다.
그래픽·음악·효과음을 포함한 모든 것을 코드로 직접 만든 오리지널 게임이며, 외부 이미지나 음원 파일은 쓰지 않았습니다.

## 게임 소개

그림자왕 모르바스가 「별의 수정」을 여섯 조각으로 부숴 버렸습니다.
별의 정령 **피피**와 함께 여섯 지역을 모험하며, 그림자에 물든 수호자들을 정화하고 별조각을 되찾아야 합니다.

| 스테이지 | 지역 | 특징 | 보스 |
|---|---|---|---|
| 1 | 그린우드 숲 | 튜토리얼 표지판, 무너지는 다리 | 가시멧돼지 브램블 |
| 2 | 수정 동굴 | 떨어지는 종유석, 가시 함정 | 수정 골렘 그라닛 |
| 3 | 산호 바다 | 전 구간 수중(헤엄치기) | 심연의 크라켄 옥토 |
| 4 | 타오르는 사막 | 모래늪(빠지면 가라앉음), 고대 유적 | 모래 웜 둔가르 |
| 5 | 구름 성채 | 움직이는 구름 발판, 낭떠러지 | 폭풍 그리폰 템페스트 |
| 6 | 그림자 성 | 용암, 천장 가시, 2단계 최종 보스 | 그림자왕 모르바스 |

- **스토리 연계**: 스테이지 시작 전과 보스 처치 후에 대화 컷신이 나오고, 각 보스가 다음 지역의 단서를 알려 주며 이야기가 이어집니다. 캐릭터마다 대사가 다릅니다.
- **캐릭터 3명**
  - 레오 (용감한 검사): 균형형, 넓은 검 베기, 파워업 시 검기 발사
  - 미나 (바람의 닌자): 가장 빠름, 2단 점프, 빠른 발차기 (체력 낮음)
  - 세라 (별빛 마법사): 원거리 마법 구슬, 파워업 시 3방향 발사 (느림)
- **난이도 3단계**
  - 쉬움: 목숨 5개, 체력 +1, 적이 느리고 수가 적음
  - 보통: 목숨 3개, 표준 밸런스
  - 어려움: 목숨 2개, 체력 -1, 적이 빠르고 단단하며 보스 체력 1.4배
- **그 밖의 요소**: 체크포인트, 부서지는 벽돌 블록, ★아이템 블록(하트·파워업·보호막·무적 별), 숨겨진 1UP 블록, 스테이지 사이 상점, 클리어 점수 집계, 자동 저장 및 이어하기

## 휴대폰에 설치하기 (APK)

1. 이 저장소에 코드가 올라가면 **GitHub Actions**가 자동으로 APK를 빌드합니다.
2. 휴대폰 브라우저로 저장소의 **Releases** 페이지를 엽니다. 가장 최근 `별조각 퀘스트 APK (빌드 N)` 항목에서 `StarshardQuest-N.apk` 파일을 내려받습니다.
   - Releases에 올라가지 않았다면, 저장소의 **Actions** 탭에서 가장 최근 실행을 열고 **Artifacts**에 있는 zip 파일을 받으세요. zip 안에 APK가 들어 있습니다.
3. 내려받은 APK를 눌러 설치합니다. 처음에는 **"출처를 알 수 없는 앱 설치"를 허용**해야 할 수 있습니다.

> 이 APK는 테스트용 디버그 서명 버전입니다. 구글 플레이 스토어에 등록하려면 별도의 릴리스 서명 키를 만들어야 합니다.

### 업데이트

빌드 3부터는 모든 APK가 같은 키(`android/app/debug.keystore`)로 서명됩니다. 버전 번호는 빌드 번호를 따라 올라갑니다(예: 빌드 5 → 버전 1.0.5).
그래서 새 APK를 기존 앱 위에 그대로 설치하면 **업데이트로 처리되고, 저장된 진행 기록도 유지**됩니다.
빌드 1·2는 빌드할 때마다 서명이 달랐기 때문에, 그 버전에서 넘어올 때만 한 번 앱을 삭제하고 설치해야 합니다.

> `debug.keystore`는 테스트 배포용 키라 저장소에 넣어 두었습니다. 플레이 스토어용 릴리스 키는 절대 저장소에 넣지 말고, GitHub Secrets 같은 비밀 저장소에 보관하세요.

## 조작 방법

| 입력 | 동작 |
|---|---|
| 왼쪽 화면을 누른 채 끌기 | 가상 조이스틱으로 좌우 이동 (누른 곳이 조이스틱 중심이 됨) |
| A 버튼 | 점프. 길게 누르면 높이, 짧게 누르면 낮게 뜀. 물속에서는 헤엄 |
| B 버튼 | 공격. 적을 물리치고 블록을 부숨 |
| 적 위로 착지 | 밟기 공격 (가시 달린 적은 제외) |
| 오른쪽 위 ∥ 버튼 / 안드로이드 뒤로가기 | 일시정지 |

PC 브라우저에서는 `← →` 이동, `Z`/`스페이스` 점프, `X` 공격, `Esc` 일시정지로 조작할 수 있습니다.

## 개발자용

### 폴더 구조

```
arcade-game/
├── www/                 ← 게임 본체 (HTML5 Canvas + JavaScript)
│   ├── index.html
│   └── js/
│       ├── core.js      공통 상수·유틸·저장
│       ├── audio.js     효과음 합성 + 자동 작곡 배경음악
│       ├── input.js     터치 조이스틱/버튼 + 키보드
│       ├── gfx.js       화면 관리, 테마 색상, 타일·배경 그리기
│       ├── sprites.js   캐릭터·적·아이템 픽셀아트
│       ├── data.js      캐릭터·난이도·상점·스토리 대사
│       ├── levels.js    6개 스테이지 지도
│       ├── world.js     물리, 플레이어, 적, 아이템, 발판, 카메라
│       ├── bosses.js    보스 6종
│       ├── ui.js        HUD, 버튼, 터치 컨트롤 그리기
│       ├── scenes.js    타이틀~엔딩 모든 화면과 게임 흐름
│       └── main.js      시작·메인 루프·앱 생명주기
├── android/             ← Capacitor가 만든 안드로이드 프로젝트
├── scripts/serve.js     로컬 테스트 서버
├── capacitor.config.json
└── package.json
```

### 브라우저에서 바로 실행

```bash
cd arcade-game
node scripts/serve.js        # http://localhost:8080
```

PC와 휴대폰이 같은 와이파이에 있으면, 휴대폰 브라우저에서 `http://<PC의 IP>:8080`으로 접속해 바로 플레이할 수 있습니다.

### 직접 APK 빌드 (Android Studio 또는 Android SDK가 설치된 PC)

```bash
cd arcade-game
npm install
npx cap sync android
cd android && ./gradlew assembleDebug
# 결과: android/app/build/outputs/apk/debug/app-debug.apk
```

필요 환경: Node.js 20 이상, JDK 21, Android SDK (compileSdk 36).

### 스테이지 지도 고치기

`www/js/levels.js`에서 글자로 지도를 그립니다. 한 스테이지는 14줄 × 32칸 크기의 구역을 가로로 이어 붙인 것입니다. 글자의 뜻은 파일 맨 위 주석에 정리해 두었습니다.
