# 06. 화면 사양

[개념 05](../concept/05-information-architecture.md)의 화면 개념을 구현 수준으로 명세합니다. Phase 1 범위의 화면만 다룹니다.

## 1. 공통

### 1.1 레이아웃

```
┌─ 상단바 ────────────────────────────────────────────────┐
│ [시험 선택 ▾]                        [사용자] [도움말]   │
├─ 좌측 내비 ─┬─ 본문 ──────────────────────────────────┤
│ Overview    │ ┌─ 좌표 바 (1.2) ───────────────────┐  │
│ D1 EDC      │ ├─ 필터 바 (1.3) ───────────────────┤  │
│ D2 RTSM     │ ├─ 본문 영역 ──────────────────────┤  │
│ Issues      │ │                                   │  │
│ Subject 360 │ └───────────────────────────────────┘  │
│ Data & Cfg  │                                         │
│ Export      │                                         │
│ [Admin]     │                                         │
└─────────────┴─────────────────────────────────────────┘
```

좌측 내비는 **권한 있는 모듈만** 표시합니다. 권한 없는 항목을 회색으로 두지 않고 숨깁니다.

### 1.2 좌표 바 (전 화면 공통, 고정)

```
스냅샷: 2026-09-14 08:00 (공식) ▾   가정 v3 ▾   설정 v2 ▾   지표정의 v1 ▾
원본 추출: 2026-09-12 (2일 전)
분모 기준:  [● Due]  [ Protocol ]  [ Forecast ▸ 2026-12-31 ]     [비교 모드]
```

| 요소 | 동작 |
|---|---|
| 스냅샷 선택 | 공식 스냅샷 우선 정렬. 선택 시 전 화면 재조회 |
| 가정·설정·지표정의 | 읽기 전용 표시. 클릭 시 해당 버전 상세로 이동 |
| 원본 추출일 | 경과일이 전송 주기의 2배를 넘으면 주황색 경고 |
| 분모 기준 토글 | **즉시 전환.** 재계산 없음 (`metric_fact`의 `basis` 필터) |
| Forecast 기준일 | Forecast 선택 시에만 나타남. 기본 = 다음 DBL 계획일 |

좌표 바는 **스크롤해도 고정**됩니다. 숫자를 보는 동안 좌표가 화면 밖으로 나가면 안 됩니다.

### 1.3 필터 바

국가 / 사이트 / 피험자 / 기간 / 저장된 뷰. 선택은 URL 쿼리에 반영되어 **링크 공유가 가능**합니다.

### 1.4 숫자 표시 규칙

| 값 | 표시 |
|---|---|
| `rate = null` | `N/A` (회색). **0%로 표시하지 않음** |
| `rate = 0` | `0.0%` |
| 지표가 꺼져 있음 | 행·열 자체를 표시하지 않음 |
| 예외(waived) | 본 숫자 옆에 `· 예외 8건` 병기 |
| 근사값 | **없음.** 추정하지 않으므로 표시할 일이 없음 |

### 1.5 지표 설명

모든 지표명 옆에 `?` 아이콘. 클릭 시 `metric_definition`의 정의문·분자·분모·제외 규칙·기한 규칙·버전을 팝오버로 표시합니다.

## 2. Trial Overview

| 영역 | 내용 |
|---|---|
| 위험 신호 | 임계 초과 지표 목록. 클릭 시 원인 화면으로 이동 |
| D1 카드 | 병행 단계 막대 (2.1) |
| D2 카드 | 등록 추이, 윈도우 이탈·미수행 건수 |
| 데이터 품질 카드 | 최근 Drop 상태, 경고 건수, Feed 신뢰도 |

### 2.1 EDC 병행 단계 막대

[개념 04](../concept/04-domain-concepts.md) 1.8의 시각화입니다.

```
  entered   ████████████████████░░  91.0%   due 12,400 / done 11,284
     ├─ SDV'd    ████████████░░░░░░  58.2%   ← 가장 뒤처짐 (강조)
     ├─ reviewed ███████████████░░░  72.4%
     ├─ coded    ██████████████████  84.1%
     ├─ frozen   ███░░░░░░░░░░░░░░░  15.0%
     └─ signed   ▸ 미서명 3,204건 (SAE 12건)      ← 막대 아님
  locked    ░░░░░░░░░░░░░░░░░░░░░░   0.0%

  예외 84건 · 분모 제외됨  [상세]
```

| 규칙 | 내용 |
|---|---|
| `signed`는 막대가 아니라 **건수 뱃지**로 표시 | rate가 존재하지 않기 때문 |
| SAE 건수는 **항상 병기** | 안전성 직결 |
| 가장 낮은 병행 단계를 강조 | 병목 식별 |
| 꺼진 단계는 줄 자체가 없음 | `review` off 시 |

## 3. 도메인 화면 (D1 / D2 공통 레이아웃)

### 3.1 구성

```
① 단계 요약      KPI 타일 + 병행 단계 막대 + 예외 병기
② 롤업 테이블    레벨 전환 [Trial][Country][Site][Subject]
③ 드릴다운 패널  ②의 칸 클릭 시 개별 항목 목록
```

### 3.2 롤업 테이블

| 열 | 내용 |
|---|---|
| 개체 | 레벨에 따라 국가/사이트/피험자 |
| 단계별 그룹 | `due` / `완료` / `backlog` / `rate` / `기한초과` / `예외` |
| 상태 표식 | rate가 임계 미만이면 셀 배경 강조 |

| 동작 | 결과 |
|---|---|
| 개체명 클릭 | 한 단계 아래 레벨로 이동 (필터 자동 적용) |
| 숫자 셀 클릭 | ③ 드릴다운에 **정확히 그 칸을 구성하는 항목**만 표시 |
| 열 정렬 | 서버 정렬 |
| `site average rate` 토글 | `overall rate`와 구분 표시 ([개념 03](../concept/03-core-concept-model.md) 6.2) |

두 번째 행이 원칙 4.3(근거까지 드릴다운)의 구현입니다. **예외 없이 모든 숫자 셀이 클릭 가능**해야 합니다.

### 3.3 드릴다운 패널

| 열 | 내용 |
|---|---|
| 피험자 / 방문 / 활동 / 반복 순번 | 식별 |
| 현재 단계 상태 | 배지 |
| 트리거일 / 기한 / 경과일 | |
| 이슈 | 건수. 클릭 시 이슈 목록 |
| 예외 | `waiver_type` + 사유 (툴팁) |

[CSV/Excel Export] 버튼이 **항상** 있습니다.

### 3.4 D2 고유 요소

| 요소 | 내용 |
|---|---|
| 방문 윈도우 이탈 분포 | 조기 / 준수 / 지연 / **미수행** 4구간 막대 |
| 피험자 상태 분포 | 상태별 건수 |
| 가상 피험자 표시 | `basis=FORECAST`일 때만 나타나며 **점선 스타일로 구분** |

미수행(`missed`)을 별도 구간으로 두는 것이 [개념 04](../concept/04-domain-concepts.md) 2.3의 제안입니다.

## 4. Subject 360

```
┌────────────────────────────────────────────────────────────────┐
│ 1023-007 │ Site 1023 (KR) │ Randomized 2026-02-14              │
│ 상태: On treatment  층화: [마스킹됨]  마지막 방문: V5 (08-20)   │
├────────────────────────────────────────────────────────────────┤
│           V1    V2    V3    V4    V5    V6(예정 09-18)         │
│ 방문      ✓     ✓     ✓     ✓+3   ✓     ○                     │
│ 입력      ✓     ✓     ✓     ✓     ▲3    -                     │
│ SDV       ✓     ✓     ▲     ✕     ✕     -                     │
│ 리뷰      ✓     ✓     ✓     ▲     -     -                     │
│ 코딩      ✓     ✓     ✓     ✓     -     -                     │
│ 서명      ✓     ✓     -     -     -     -                     │
│ 쿼리      -     1     -     2 open -     -                     │
├────────────────────────────────────────────────────────────────┤
│ ⚠ V4 방문이 윈도우 +3일 초과                                    │
│ ⚠ V4·V5 SDV 기한 초과 (각 12일, 5일)                            │
└────────────────────────────────────────────────────────────────┘
```

| 기호 | 의미 |
|---|---|
| `✓` | DONE |
| `▲n` | PENDING (n = 기한까지 남은 일수) |
| `✕` | OVERDUE |
| `⊗` | WAIVED |
| `-` | NOT_APPLICABLE / NOT_DUE |
| `○` | 미발생 예정 |

각 칸 클릭 시 해당 항목의 상세와 이력이 열립니다.

## 5. Issues

| 요소 | 내용 |
|---|---|
| 탭 | 전체 / OPEN / ANSWERED / 기한 초과 |
| 분해 축 | 소유자(DM/CRA/MM/PV) / 그룹 / 유형 |
| aging 분포 | 0-7 / 8-14 / 15-30 / 30+ 구간 막대 |
| 행 동작 | 상세 열람, `unresolvable` 설정(WRITE 권한 + 사유) |

소유자별 기한이 다르므로 **기한 초과 판정은 소유자별 설정을 적용**합니다 ([03](03-engine-spec.md) 3.6).

## 6. Data & Configuration

### 6.1 Data Drops

| 열 | 내용 |
|---|---|
| 업로드 일시 / 업로더 | |
| Feed / template·mapping 버전 | |
| **원본 추출일** | 파일 작성일과 구분 표시 |
| 전송 유형 | `CUMULATIVE`/`INCREMENTAL` (증분은 기간 병기) |
| 행 수 | 전체 / 반영 / 거부 / 경고 |
| 상태 | 배지 |

상세 화면에서 검증 리포트를 보고 확정·폐기합니다. `C2`·`C3`·`X4` 경고는 **상단 배너**로 강조합니다.

### 6.2 Source Templates

template 다운로드, Mapping Profile 편집, **매칭 키 선언**. 입도가 권고 미달이면 경고와 함께 Feed 신뢰도가 `CAUTION`으로 표시됩니다.

### 6.3 Trial Configuration

| 요소 | 내용 |
|---|---|
| 버전 목록 | 상태, 적용일, 변경 사유 |
| 버전 비교 | 설정 항목별 diff |
| 업로드 | `CFG01`~`CFG09` 워크북 |
| 활성화 | **사유 필수.** 엔진 전체 재실행 경고 표시 |

### 6.4 Metric Definitions

지표 목록과 정의 상세. 시험별 on/off 상태와 사유를 함께 표시합니다.

## 7. Admin

| 화면 | 기능 |
|---|---|
| Users | 목록, 생성, 비활성화. **삭제 없음** |
| Roles | 역할 정의, 모듈별 접근 수준, 눈가림 해제 권한 |
| Trial Assignments | 사용자-시험-역할-범위 |
| Audit Trail | 검색. **행위자 구분(사람/AI/엔진) 필터** |
| System Settings | 소스 시스템 등록, 전역 설정 |

감사 조회는 `actor_type`, `entity_type`, 기간, 시험으로 필터하며 CSV export가 가능합니다.

## 8. 상호작용 공통

| 기능 | 사양 |
|---|---|
| 저장된 뷰 | 필터·레벨·정렬·분모 기준을 이름 붙여 저장. 팀 공유 가능 |
| 비교 모드 | 두 스냅샷 나란히. 설정·지표정의 버전 차이 시 경고 배너 |
| Export | 모든 테이블에 버튼. 예외 없음 |
| 알림 | Phase 1은 **이메일 요약만.** 앱 내 알림 센터는 후속 |

## 9. 접근성·표시

| 항목 | 사양 |
|---|---|
| 대상 | 데스크톱 전용 (1280px 이상) |
| 색상 | 상태를 색으로만 구분하지 않고 기호를 병행 |
| 언어 | 한국어 기본, 영문 전환 대비해 문자열 외부화 |
| 숫자 | 천 단위 구분, 비율은 소수점 첫째 자리 |
